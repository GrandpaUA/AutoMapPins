# Support

Use [GitHub Issues](https://github.com/GrandpaUA/AutoMapPins/issues) for **all bug reports, questions, configuration help, and feature requests**. English and Ukrainian are welcome.

Search existing issues first. Add evidence to an existing issue when it describes the same problem; open a separate issue for a different problem. Pick the matching form from [New issue](https://github.com/GrandpaUA/AutoMapPins/issues/new/choose).

For bugs, include AutoMapPins, Valheim, and BepInEx versions; reproduction steps; relevant AMP configuration; other map/skill/UI mods; and `BepInEx/LogOutput.log` from the affected session. Before/after screenshots help distinguish reload problems from startup problems.

Remove credentials, server connection details, and private messages from uploads. A mod manager's profile export can contain more than the AMP settings.

Known boundaries:

- Normal discovery uses loaded game objects in explored areas. A larger exploration radius does not generate distant zones.
- Previously generated-zone scanning is experimental and off by default. Its multiplayer behavior still needs field testing.
- AMP pins are deliberately excluded from cartography-table sharing because players can use different category and permanence settings.
- Exploration and Sailing are optional integrations. Include their exact versions when reporting radius or skill problems.
