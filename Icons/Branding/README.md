# AutoMapPins logo

The current mod logo recreates the location-pin-over-folded-map reference supplied by GrandpaUA. Its dark brown and golden yellow palette follows the neighboring [CraftSort](https://github.com/GrandpaUA/CraftSort) mod.

- `AutoMapPins-logo-master.png`: generated high-resolution master, 1254 × 1254.
- `../../ThunderStorePackage/icon.png`: 256 × 256 PNG used by the mod package, exported from the master with Lanczos downsampling.
- Palette reference from CraftSort: dark brown `#1C0F06`, golden yellow `#FFD126`. The raster artwork includes antialiasing and slight generated color variation.

The logo was generated using the built-in image generation tool from the supplied shape and palette references. It contains no text and does not alter the embedded map-pin artwork.
